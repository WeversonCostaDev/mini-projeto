Relatório de uso de IA generativa
(a) Ferramentas utilizadas
Foi utilizado o ChatGPT, uma ferramenta de IA generativa, como apoio durante o desenvolvimento do projeto de gestão de estoque feito com TypeScript, Vite e JSON Server.

A ferramenta foi usada para esclarecer dúvidas, explicar conceitos, analisar trechos de código, investigar erros e sugerir possíveis correções. As sugestões foram avaliadas e aplicadas durante o desenvolvimento, com testes no próprio projeto.
(b) Exemplos de prompts utilizados
Alguns exemplos de perguntas feitas durante o desenvolvimento:
- “Qual a melhor forma de organizar as operações da API em uma classe TypeScript?”
- “Quando devo utilizar uma classe e quando uma função comum é suficiente?”
- “Como utilizar o debounce para evitar muitas requisições durante a pesquisa?”
Essas perguntas ajudaram a compreender recursos como fetch, async/await, FormData, Promise, tipagem, eventos, debounce, atualização parcial com PATCH e orientação a objetos.
(c) Considerações sobre o uso de IA generativa no desenvolvimento de software
A IA generativa pode ajudar no dia a dia do desenvolvimento ao acelerar a investigação de erros, explicar mensagens técnicas, apresentar exemplos e sugerir alternativas de implementação. Ela também pode servir como apoio para consultar conceitos sem interromper tanto o fluxo de trabalho.

Por outro lado, suas respostas podem estar incorretas ou não se encaixar no contexto do projeto. Por isso, é importante analisar as sugestões, entender o código antes de utilizá-lo e testar as alterações. A IA deve ser uma ferramenta de apoio, e não substituir a responsabilidade do desenvolvedor pelas decisões e pelo resultado final.
(d) Considerações sobre o uso de IA durante o aprendizado de uma nova tecnologia
Durante o aprendizado de TypeScript e das ferramentas utilizadas no projeto, a IA foi útil para explicar conceitos novos de forma gradual e relacioná-los a exemplos práticos do próprio código. Também permitiu tirar dúvidas específicas conforme surgiam dificuldades.

O principal benefício é facilitar a compreensão e ajudar a encontrar caminhos para resolver problemas. Entretanto, copiar uma solução sem entendê-la pode prejudicar o aprendizado. Por isso, considero importante pedir explicações, comparar alternativas, testar o que foi sugerido e procurar compreender por que a solução funciona.
